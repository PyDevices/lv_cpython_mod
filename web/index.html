lvgl-python — CPython & Pyodide WASM LVGL extension.

lvgl-python provides the desktop CPython extension and WebAssembly wheels for LVGL. It allows the exact same LVGL python code to run on Linux, Windows, macOS, Android (via python-for-android), and inside desktop web browsers via Pyodide.

GitHub Repo lvgl-bindings cmods Workspace pydevices Core

Installation Workflows

Precompiled binary wheels published on TestPyPI & GitHub Releases 
# Install CPython extension on Desktop (Linux / Windows / macOS):
pip install --extra-index-url https://test.pypi.org/simple/ pydevices-lvgl

# Pyodide / PyScript Browser Integration:
import pyodide
await pyodide.loadPackage("https://pydevices.github.io/pydevices-examples/web/pyscript/wheels/lvgl-0.1.0-cp311-cp311-emscripten_3_1_46_wasm32.whl")
